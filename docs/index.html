🛠 Funcionalidades
🎨

Personalização do Windows

  • Papel de parede padrão (Windows claro)
  • Proteção de tela desativada
  • Tela de bloqueio restaurada (Spotlight)
  • Ponteiros Aero no tamanho padrão
  • Cores e modo claro automáticos
  • Histórico de navegação limpo
  • Lixeira esvaziada
🔍

Varredura de Arquivos

  • Visualização em cascata (hierárquica)
  • Escolha quais pastas varrer
  • Expande/recolhe subpastas
  • Seleciona por pasta ou individualmente
  • Exclusão permanente dos itens marcados
⚡

Automação Completa

  • Restaura tema + varre + exclui em 1 clique
  • Confirmação opcional antes de excluir
  • Modo totalmente automático
🗓

Agendamento

  • Inicialização automática com o Windows
  • Para todos os perfis ou só o atual
  • Limpeza periódica a cada X dias
  • Executa em segundo plano (tray)
👥

Gerenciamento de Usuários

  • Lista usuários locais com status
  • Altera senha e nome completo
  • Configura expiração de senha
  • Ativa ou desativa contas
  • Suporte a credenciais de admin
🔄

Atualização Automática

  • Verifica novas versões no GitHub
  • Download direto dentro do programa
  • Substitui e reinicia automaticamente
  • Sem necessidade de reinstalar
📋 Como Usar
1

Baixar

Clique no botão de download acima e salve o WB_SystemCare.exe

2

Executar

Dê duplo clique no arquivo — não precisa instalar nada

3

Personalizar

Escolha as pastas e opções que deseja restaurar ou limpar

4

Limpar

Clique em Escanear, marque os itens e exclua o que não precisa

🔄

Atualização Automática

Quando uma nova versão é lançada, o programa detecta automaticamente.
Basta clicar em "⬇ Baixar Nova Versão" na aba Atualização — o programa faz o download, substitui o arquivo atual e reinicia sozinho.
Não é preciso baixar manualmente nem reinstalar.

🎓 Contexto de uso: Desenvolvido para laboratórios de informática com cursos de 5 a 14 dias. Ao final de cada curso, o programa restaura o computador para o estado padrão e remove os arquivos dos alunos, preparando a máquina para a próxima turma — sem precisar reinstalar o Windows.

🔐 Segurança: Opera exclusivamente no perfil do usuário que está executando o programa. Não afeta outros usuários nem arquivos do sistema.
